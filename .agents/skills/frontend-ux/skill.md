# Frontend UX Manager

**Animaciones**: Usa framer-motion para transiciones de vista (fade-in) y modales. Usa auto-animate para listas dinámicas (ej. añadir/quitar series).

**Feedback**: Todo guardado exitoso o error en la base de datos debe disparar un toast de sonner.

**Estética**: IronForge requiere fondo zinc-950, bordes afilados (rounded-sm), sin emojis, estilo brutalista técnico.
